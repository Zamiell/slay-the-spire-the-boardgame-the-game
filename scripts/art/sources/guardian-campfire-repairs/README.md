# Guardian campfire repairs

These 64 approved native 3840×2160 sources replace Guardian parties containing Ironclad-chan or Defect-chan. Each request uses only the original empty campfire and one original identity asset per party member. Seated cutouts and previous generated outputs are excluded.

The prompts, ordered input hashes, source hashes and runtime hashes are recorded in [the fresh campfire manifest](../../../../docs/skins/fresh-campfires/manifest.json). Generation uses the bundled Imagegen CLI with `gpt-image-2`, high quality. Rebuild with `python3 scripts/art/export-fresh-campfires.py`; runtime conversion duplicates the bottom row and encodes WebP without resizing.
